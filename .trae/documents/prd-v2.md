# Python数据分析学习平台 - 产品需求文档 (PRD)

## 1. 项目概述

### 1.1 项目背景
本项目是在现有"商析学堂"React项目基础上的全面重构，目标是将一个通用商务数据分析平台改造为**专注于Python数据分析的在线学习平台**，提供系统化的课程学习、在线练习刷题、数据统计追踪等完整学习体验。

### 1.2 产品定位
- **目标用户**：Python数据分析初学者、商务数据分析专业学生、希望提升Python数据分析能力的职场人士
- **核心价值**：通过系统化的Python数据分析课程体系 + 交互式在线练习 + 学习数据追踪，帮助用户高效掌握Python数据分析技能

### 1.3 现有资产利用
- ✅ 保留现有项目结构（Vite + React + TypeScript + Tailwind CSS）
- ✅ 保留现有依赖（Zustand、React Router、Monaco Editor、Pyodide、Recharts、Lucide Icons）
- ✅ 保留现有路由架构
- ✅ 保留现有存储机制（localStorage持久化）
- ❌ 废弃现有课程数据（重新构建Python数据分析专用课程）
- ❌ 废弃现有成就系统（简化为进度统计）
- ❌ 废弃Projects页面

## 5. 数据结构设计

### 5.1 类型定义
```typescript
// 章节
interface Chapter {
  id: string;
  title: string;
  difficulty: 'beginner' | 'intermediate' | 'advanced';
  content: string;          // Markdown格式
  codeExamples: CodeBlock[]; // 代码示例
  exercises: ChapterExercise[]; // 章节内练习
}

// 代码块
interface CodeBlock {
  id: string;
  language: string;
  code: string;
  explanation?: string;
}

// 章节内练习
interface ChapterExercise {
  id: string;
  type: 'single-choice' | 'multiple-choice';
  question: string;
  options: string[];
  correctAnswer: string | string[];
  explanation: string;
}

// 练习题库题目
interface PracticeQuestion {
  id: string;
  chapterId: string;
  chapterTitle: string;
  type: 'single-choice' | 'multiple-choice' | 'coding';
  difficulty: 'beginner' | 'intermediate' | 'advanced';
  question: string;
  options?: string[];
  correctAnswer: string | string[];
  explanation: string;
  codeTemplate?: string;
  expectedOutput?: string;
}

// 学习进度
interface LearningProgress {
  completedChapters: string[];    // 已完成章节ID
  currentChapterId: string | null; // 当前学习章节
  chapterTimestamps: { [chapterId: string]: number }; // 完成时间
}

// 练习记录
interface PracticeRecord {
  questionId: string;
  userAnswer: string | string[];
  isCorrect: boolean;
  timestamp: number;
  timeSpent?: number;  // 答题耗时（秒）
}

// 错题本
interface WrongQuestion {
  questionId: string;
  question: PracticeQuestion;
  userAnswer: string | string[];
  correctAnswer: string | string[];
  wrongCount: number;  // 错误次数
  lastWrongTime: number;
}

// 用户状态
interface UserState {
  progress: LearningProgress;
  practiceRecords: PracticeRecord[];
  wrongQuestions: WrongQuestion[];
  theme: 'light' | 'dark';
  lastVisitChapter: string | null;
}
```

### 5.2 题库规模
| 题型 | 每章题量 | 总题量 |

| 选择题（单选） | 5-8题/章 | ~100题 |
| 选择题（多选） | 2-3题/章 | ~35题 |
| 编程实操题 | 2-3题/章 | ~40题 |
